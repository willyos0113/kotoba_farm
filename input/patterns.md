# 文型（patterns）

---

## 「Aは悪くない、問題はB」

- 出典：まめとむぎ ep3
- 台詞：「あのね、菌たちは悪くないの、みんな悪玉菌と呼んだりするけど、菌が邪悪なんじゃなくて、人間に都合の悪い菌ってことなの」

### なぜ「が」ではなく「は」か（助詞の使い分け）

- 菌たち**は**悪くないの → 「菌については」と話題を立てる。菌はすでに話題に出ている既知の主題
- 菌たち**が**悪くないの → 「悪くないのは菌たちだ」と指定する（「誰が？」への答え）。複数の候補から選ぶ場面でないと使いにくい

### 「は」が支えている語感

- 対比が裏にある：悪いとされる菌 vs 決めつけている人間。「悪いのは菌じゃなくて、人間の都合のほうなんだよ」という含み
- 話し手の主張・断言のトーン（「私の考えでは」）。菌を擁護する語り方に合う
- 文末の「の」：柔らかく説明する言い方（「～なんだよ」に近い）。親しい間柄・女性寄りの語感。押しつけにならない

### 短い例文での対照

- 「あの子は悪くないよ」→ あの子を擁護。他の誰かが悪いことを匂わせる
- 「あの子が悪くないの」→ 「悪くないのはあの子だ」と指定。普通は言わない

### 自分で使うとき（ストーリー紹介・評論で使える型）

- 型：「Aは悪くない、問題はB」。AとBを対にして、原因・責任は別のところにあると整理する
- 例：
  - 「脚本は悪くないんだよ、ただ演出が合わなかった」
  - 「主人公は悪くないの、周りが勝手に決めつけてるだけ」
- 台詞（キャラクターの発言）だが、感想・考察でそのまま使える型

## 気持ちの形容詞：対象は「が」、「は」だと対比・客観寄り

- 出典：まめとむぎ ep3
- 台詞：「まっすぐに謝れるまりなさん**が**眩しかったんだと思う、それで八つ当たりをしてしまいました」

### なぜ「が」か

- 「眩しい」は話し手の気持ちを表す形容詞。好き・怖い・羨ましい・眩しいなどは、気持ちの向かう先（対象）を「が」で示す
  - 「あの人が羨ましかった」「犬が怖い」
- 「まりなさんを見て、自分がそう感じた」という気持ちの動きそのものを言っている
- 「眩しかった（原因）→ 八つ当たりをした（結果）」という流れにも合う。反省・自己分析の台詞なので、気持ちの正直さが出る

### 「は」に変えると

- 文法的には通る。ただし語感が変わる
  - 対比が出る：「（私と違って）まりなさんは眩しかった」
  - 相手の評価に寄る：「私が感じた」から「まりなさんはこういう人だ」という説明に近づく
  - 原因から結果への流れが弱くなる
- 距離を置いた、客観的な聞こえ方になる（評論のよう）

### 「は」の二つの働き

- 主題：「この店は美味しい」。ただ話題を立てるだけで、対比の含みは薄い
- 対比：「この店は美味しい（けど、あの店は…）」。対比できる相手が文脈にあるとき、または強く言うときに出る
- 「は」がつけば必ず対比、というわけではない

### 短い例文での対照

- 「犬が怖い」→ 犬に対する恐怖そのもの
- 「犬は怖い」→ 「猫は平気だけど、犬は怖い」という対比が出る
- 「あのシーンが泣けた」→ 自分の素直な反応
- 「あのシーンは泣けた」→ 「全体は微妙だったけど、あのシーンは」という含み。評価に近づく

### 自分で使うとき（感想・評論で使える型）

- 型：「Xが＋気持ちの形容詞」は素直な反応、「Xは＋形容詞」は他と比べた評価
- 作品の感想で使い分けると、「ただ感動した」のか「部分的に評価している」のかが伝わる
- 台詞（登場人物の発言）だが、感想・考察でそのまま使える型

## 「は」は主題を取り上げる助詞：「は」の前は主語とは限らない

- 出典：まめとむぎ ep2・ep3・ep4・ep5
- 台詞：
  - 「滞在時間が短い、メニューはどれも評判**は**いいのに」（ep2）
  - 「自分ひとりの力でいい雑誌**は**作れる」（ep3）
  - 「これから**は**隣にいるから」（ep4）
  - 「空いて**は**いるけど、」（ep5）
  - 「菌たち**は**悪くないの」（ep3）も同じ主題の「は」（→ 上の型）
- 気づいたきっかけ：自分の思い込み「は＝主語を示す助詞」が、実際は違っていた（2026-11-16）

### 主題と主語は別のこと

- **主語**：述語の主体（誰が・何が）。文の中の役割
- **主題**：「これについて言うと」と取り上げた話題。話し手が選んだ、話の入口
- 重なることが多い（「私は学生です」）ので、「は＝主語」と思い込みやすい。でも別のもの
- 「は」の前には、主語・目的語・時・述語の一部など、いろんな成分が来る
- 日本語は主語を省略するので、「は」の前を見ても主語は分からない。主語は述語で判断する

### 「は」の前に何が来ているか（元の助詞に戻して確認）

- 評判**は**いい ← 評判**が**いい（主語）
- 菌たち**は**悪くない ← 菌たち**が**悪くない（主語）
- いい雑誌**は**作れる ← いい雑誌**を**作れる（目的語）。主語（私が）は省略
- これから**は**隣にいる ← 「これから」は時を表す言葉。主語（私が）は省略
- 空いて**は**いる ← 戻せない。「空いている」の間に「は」が入った形（述語の一部）
- 「このカレー**は**私が作りました」← カレー**を**。主題は「カレー」、主語は「私が」
- 戻せない場合や、「を」「に」に戻る場合は、「は」の前は主語ではない

### 「は」が支えている語感

- 取り上げる＝他のものは別、という含みが出る。これが対比の「は」
  - 評判は（いいけど、滞在時間は短い）
  - いい雑誌は（作れるけど、売れるかは別）
  - これからは（今までは違ったけど）
  - 空いてはいる（けど、貸せるとは言っていない）＝部分肯定
- 後ろに逆接（けど・のに）や否定が続くと、対比が前に出る
- 「は」がつけば必ず対比、というわけではない（「の二つの働き」を参照）

### 短い例文での対照

- 「このカレーは私が作りました」→ カレーについて言うと、作ったのは私（主題＝カレー、主語＝私）
- 「このカレーを私が作りました」→ 出来事をそのまま報告。話題を立てない
- 「空いている」→ 事実だけ
- 「空いてはいる」→ 「でも…」が続く。一部だけ認める

### 自分で使うとき（書くときのチェック）

- 型：「Xは＋（対比）〜けど、Yは〜」「〜ては、いる（けど）」「Xは＋Yが＋述語」（このドラマは主演が良かった）
- 書く前のチェック：
  1. 「は」を書く前に、元の助詞（が・を・に）に戻せるか考える。主語は「は」ではなく述語で判断する
  2. 対比の含みを出したくない中立的な報告は、「が」「を」にする
  3. 一文に「は」が二つ以上あるなら、主題は一つ、残りは対比。意図した対比か確認する
  4. 逆接（けど・のに）を続ける形は、対比の「は」の便利な型（「評判はいいのに」「空いてはいるけど」）
- 例：
  - 「映像は綺麗だったけど、脚本は微妙だった」（対比の型）
  - 「このドラマは主演が良かった」（主題＝ドラマ、主語＝主演）
- 台詞（登場人物の発言）だが、感想・考察でそのまま使える型
- 中文補充：「は」是「提題」,不是「主語」標記;對比是「提出來談」附帶產生的「其他另當別論」的語感
